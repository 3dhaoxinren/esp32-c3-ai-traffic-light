# AI 指示灯 3.1.0 · Nano / ESP32-C3 统一版

## Windows 便携版

在 [v3.1.0 Release](https://github.com/3dhaoxinren/esp32-c3-ai-traffic-light/releases/tag/v3.1.0) 下载 `AI-Lamp-3.1.0-win-x64.zip`。适用于 Windows 10 / 11 x64。**完整解压**，双击 `AI-Lamp.exe`；不要单独移动 EXE，旁边的 `_internal` 是运行库。不需要安装 Python。界面使用系统浏览器，关网页不退出后台，退出请用 Windows 托盘菜单。首次使用登录启动、自动连接、跟随请在「AI指示灯」页保存开关。

- **灯控调试**：USB 选自己的 Nano/ESP32-C3 串口；Wi-Fi 可点「搜索局域网灯板」或手填 IP。搜索只检查本电脑的私有直连网段（最多两个 /24），验证 TCP 8080 的灯控回执，不自动建立控制连接、不修改灯态。发现灯板后仍需点击「连接灯控」。用自定义端口的旧灯请手填。跨网段、访客隔离或防火墙阻止时不一定能发现。
- **C3 音频（当前源码）**：在时间线上拖选，再点对应状态的「绑定选段」，不必填写编号；空闲、运行、等待、报错、完成、离线可分别绑定。点标尺定位，空格播放/暂停，支持整段、选段、循环和按状态试听。需要实体按键曲目、USB 读回或手动编号时，展开「高级 · 按编号管理语音」。
- **设备试听与管理（当前源码）**：配套 [C3 固件](../C3_MaxPreview) 支持 USB/Wi-Fi 实时试听与查看已存录音。实时试听走 C3 的 12 KiB RAM 缓冲，不创建文件、不占 Flash 音频分区；「写入状态播报」才会持久保存。已存录音可在 C3 上点播，删除只允许通过 C3 原生 USB，并会清除该录音关联的状态。旧版 C3 固件可继续使用已有功能，但无法完整列出或删除录音，也不支持实时试听；旧固件的自动分配编号请通过 USB。
- **顶部实体按键与默认音量（当前源码）**：顶部按键可随机播全部已存录音，也可只播自选歌单。至少两段可播时不会连续播到同一段；选段可直接写入歌单，原有录音也可点「加入按键歌单」。移出歌单不删除录音。用「保存为开机默认音量」将 0–9 档存入 C3，断电后保留；试听音量不会改变设备默认档位。
- **不写入的直接播报（当前源码）**：在「灯控调试」通过局域网连接配套 C3，在音频页输入文字后点「直接播报到 C3」。不需要 USB、音频编号或状态绑定，不保存播报、不替换当前剪辑，不改变灯和设备音量设置。语音包可选 Windows 离线或四个在线神经音色；只有主动选择在线音色生成时，文本才发送到在线语音服务。不联网时使用本机语音。
- **电脑试听文字（当前源码）**：输入文字后可以直接用所选音色和语速在电脑上试听。不需要连接 C3，也不覆盖剪辑区。选用在线音色时，主动点试听也会把文字发给语音服务。
- **电脑试听已存录音（当前源码）**：用支持配对回读的 C3 固件，首次接原生 USB 并点「配对局域网回读」；灯控可继续用 Wi‑Fi。之后只要给 C3 供电，在列表点「电脑试听」即可经局域网加密回读，不覆盖剪辑或改变灯态。旧固件仍只能通过原生 USB 回读。「用 C3 试听」仍由设备喇叭播放。
- **附近 Wi-Fi**：C3 音频页展开 USB 配网，可以搜索并填入 Windows 看得到的网络；只填名称，不读取或自动填入密码。C3 需要 2.4 GHz。搜索受网卡和系统位置权限限制，也可以手动输入。
- **高级 AT**：默认隐藏，需手动展开。Nano 接线页不再显示，Nano USB 和旧灯 Wi-Fi 灯控仍可用。AT、透传、OLED 等旧设备相关功能保留。
- 一次只接管一块灯板。若还在运行旧版，请从旧版托盘退出，再启动统一版。统一版不会调用旧 EXE。

常用录音格式尝试由系统浏览器解码；特殊格式可另装 FFmpeg 并放进 PATH。文字合成是 Windows SAPI，中文需系统已安装中文语音。部分 Nano 需要 CH340 驱动。发布包不是烧录工具，不包含设备配置、音频或固件备份。

## 从源码运行和复现

在本目录运行：

```powershell
python -m pip install -r requirements.txt
python server.py
```

要复现 Windows 便携版，安装 PyInstaller 6.21.0 后执行：

```powershell
.\build-windows.ps1 -OutputDirectory .\dist -WorkDirectory .\build\pyinstaller
```

软件回归：`python -m unittest discover -s tests -p "test_*.py"`。固件和 TCP 实验需用 [仓库的 C++ 主机测试桩](../tests/host)，设置 `FIRMWARE_HOST_QA` 指向测试程序。运行离线包检查：`AI-Lamp.exe --self-test report.json`（生成回执，只在演示模式检查本机页面、托盘资源和音频裁切，不接触灯板）。

后台只监听 127.0.0.1。接入第三方 AI 可使用 `ai_signal.py` 或 `claude_hook.py`，也可从命令提示符运行 `AI-Lamp.exe --signal running --source custom-ai --session task-1`。
