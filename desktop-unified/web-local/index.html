Nano 灯板连接

电脑 USB → Nano → 红黄绿灯

R → D4，Y → D5，G → D6，公共 GND → GND。沿用带限流电阻的共阴极灯板，Nano 由 USB 供电。
只需 Nano 和 LED。原有灯控固件可直接使用，无需连接 Wi-Fi 模块或屏幕。


手动调试
手动切换灯色会暂停 AI 跟随，查询状态不会。断开连接会暂停本次自动重连。


开机自启与自动连接
没有唯一序列号的 Nano 按上次 USB 位置匹配；换插口后手动连接一次。

灯色与灯效
红灯 D4 支持常亮或闪烁；黄灯 D5、绿灯 D6 支持呼吸。离线固定熄灯。
关闭网页后托盘继续运行。右键托盘可直接点击“已查看，恢复正常”。本地版只控制 USB，不发 Wi-Fi、AT 或 OLED 指令。
