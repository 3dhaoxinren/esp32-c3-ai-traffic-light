python .\server.py --signal running --source Claude --session task-1 --ttl 120
python .\server.py --signal waiting --source Claude --session task-1 --ttl 3600
python .\server.py --signal idle --source Claude --session task-1 --ttl 3600
状态包括 running、waiting、error、idle、offline；长任务每 15 秒发送 heartbeat。本目录的 ai_signal.py 和 claude_hook.py 都复用统一版的本机接入端点。未配置接入的 AI 不会被自动识别。
