# LU-ASR01 + Nano：语音控制与状态播报

当前进度：Nano 候选程序已编译；天问积木工程已用官方生成器转成 C++，应用目标文件已编译。**语音模型尚未生成，语音板和 Nano 均未刷入本次程序，尚未做实物联调。**

## 先做什么

1. LU-ASR01 单独接电脑 USB 时会枚举串口。COM 号因电脑而异；不要把 Arduino 程序上传到它。
2. 在天问账号登录后，使用支持 TWEN-ASR 的天问 Block V2025 打开 `LU-ASR01_AI指示灯.hd`，生成唤醒词、识别词及播报音频模型，再按官方流程编译并下载完整语音固件。仅有应用 `.o`、`.cpp` 或 SDK 自带示例 BIN 都不能代替本工程固件。
3. Nano 改接电脑时重新识别端口；用 `Nano_HLK_M30_Voice/Nano_HLK_M30_Voice.ino` 编译上传，板型为经典 Nano / ATmega328P（Old Bootloader）。
4. **两块板均更新完成后，断电按 `voice-wiring.png` 接线。** 原厂语音示例的 IO 方向可能不同，不能先把 Nano 输出接过去。
5. 分别供电，确认启动播报，再测试下表口令；最后连接工作台并开启 AI 自动跟随，测试状态播报。

## 用法

先说“小鹿同学”，听到“我在”后说口令。

| 口令 | 行为 |
| --- | --- |
| 打开红灯 / 打开黄灯 / 打开绿灯 | 指定灯常亮，进入语音手动接管 |
| 关闭灯光 | 关灯，持续保持；AI 心跳不会重新点亮 |
| 恢复跟随 | 退出语音接管；有 15 秒内的新鲜 AI 状态时恢复灯效，否则熄灯 |
| 播报状态 | 播报当前模式或 AI 状态；受最短播报间隔限制 |

识别口令后回复“收到”仅表示语音识别成功，不代表 Nano 执行成功。工作台收到 Nano 的 VOICE 回执后才显示“语音接管”。这套 GPIO 接口没有语音板播放完成回执，不能据此显示“语音板在线”或“已播放”。

自动播报包括：未接入或状态失效、空闲、处理中、等待确认、任务异常、手动控制。状态稳定 600 毫秒才安排播报，间隔至少 3.5 秒；快速变化优先播报最新状态。同一个状态不随 AI 心跳重复播放。

“恢复跟随”需要电脑工作台原本已经开启自动跟随；它不会替电脑开启功能。工作台的手动灯控按钮会退出语音接管，暂停并熄灯也会执行关灯。手动接管不保存到 EEPROM，Nano 断电重启后恢复默认熄灯。

离线语音灯控不需要电脑。AI 状态播报仍需电脑后台运行并通过 Wi-Fi 或 USB 把状态送到 Nano。这里是预置短句播报，不是任意文字 TTS。

## 接线

适用于照片中的 **LU-ASR01 + 经典 5V Nano（ATmega328P）**。语音板排针顺序：`5V G TX DHT IO8 IO7 IO6 IO5 IO4 IO3 IO2 IO1`。

### 语音板发口令给 Nano

| LU-ASR01 | Nano | 额外元件 |
| --- | --- | --- |
| IO1 | D2 | 此节点接 10kΩ 到 GND |
| IO2 | D3 | 此节点接 10kΩ 到 GND |
| IO3 | D7 | 此节点接 10kΩ 到 GND |
| IO4 | D8 | 此节点接 10kΩ 到 GND |

共 4 个独立下拉电阻。IO1～IO3 是数据位，IO4 是提交位；3.3V 输出接 Nano 输入。不要启用 Nano 的 5V 内部上拉。

### Nano 发状态给语音板

| Nano | LU-ASR01 | 每根线都需要分压 |
| --- | --- | --- |
| A0 | IO5 | A0 → 10kΩ → IO5；IO5 → 20kΩ → GND |
| A1 | IO6 | A1 → 10kΩ → IO6；IO6 → 20kΩ → GND |
| A2 | IO7 | A2 → 10kΩ → IO7；IO7 → 20kΩ → GND |
| A3 | IO8 | A3 → 10kΩ → IO8；IO8 → 20kΩ → GND |

**分压交点在语音板输入一侧**，四个交点不能接在一起。5V 经 10kΩ / 20kΩ 分压约为 3.33V；单串一个电阻不能代替分压。20kΩ 可用两个 10kΩ 串联。A0～A3 在本程序中作为数字输出。

新增元件合计：10kΩ × 8、20kΩ × 4（或全部用 10kΩ × 16）、连接线和面包板。板上的 TX、DHT 本方案不接。

### 电源与原接线

- 初次联调：语音板和 Nano 分别用各自 USB 供电，**只连公共 GND，不把两路 5V 接在一起**。两板一起上电、断电，避免给未上电的板灌入信号。
- 独立运行：可用有足够余量的稳压 5V 电源给语音板与 Nano 的 5V 引脚供电；整套建议 5V / 2A。此时先拔掉两块板的 USB，避免并接电源。语音板不能从 Nano 的 3V3 引脚供电。
- HLK-M30 保持原来的独立稳压 3.3V，不能接 5V。M30 TX → D10；D11 经原有 10kΩ / 20kΩ 分压 → M30 RX。串口仍为 9600。
- 灯板 R → D4、Y → D5、G → D6，所有 GND 共地。灯板自带限流电阻。
- 喇叭接语音板原来的双线插座，保留原喇叭规格；两根喇叭线都不接 GND。

## 联调验收

1. 不开 AI 跟随，依次说红、黄、绿、关闭，观察每条指令只执行一次。
2. 开启自动跟随，运行中说“关闭灯光”，等待超过 2 次心跳，灯仍应灭。
3. 说“恢复跟随”，检查灯效与工作台 AI 目标一致。
4. 切换 AI 状态，检查预置播报；同状态持续 20 秒不应反复播报。
5. 在语音手动模式点击工作台“暂停并熄灯”，灯应灭；与普通离线心跳的保持行为区分。
6. AI 跟随中中断网络，15 秒无心跳后 Nano 熄灯，再播报状态失效。语音手动模式下网络断开不会取消手动灯色。
